# Original Twelfth Hour art

Generated on 19 October 2026 using the built-in **imagegen** tool, then compiled by `tools/prepare_twelfth_art.py` and the collection's deterministic `standardize_icons.py` pipeline. Final game assets live under `TheTwelfthHour/Art`; retained PNGs here allow reproducible crops/conversion without regeneration. Alpha clock and pendulum-polearm flag are simple original code-drawn silhouettes. No prior civilization's assets were replaced.
