# Exact engine restrictions — mod version 4

Release 1.2.0 is an implementation preview. Nine simulations and 176 official CP v151 source assertions pass; live Civ V tests remain outstanding. [EngineCompletionReport.md](EngineCompletionReport.md) gives causes, APIs, code, tests and all six requested statuses. Lua save schema is 3; BCY2 is unchanged.

| Requirement | Result and remaining restriction |
| --- | --- |
| Unlimited cultural/remote distance | Preserved: cached capital-connected frontier and any-distance eligible owned virtual plots. Finite map/native ownership still apply. |
| Original-capital recovery | **PARTIALLY SOLVED:** native zero-city survival while units remain and a deferred siege Reclaim action for the genuine original only, with zero cities/war/visibility/1 HP/eligible melee. Ordinary attack-click capture remains NoCapture-blocked. Eliminated players cannot reclaim; no resurrection. Max-city-elimination still applies. |
| Old-save survival flag | Native traits serialize the old value; upgraded v1–3 saves may need a normal technology/policy refresh before the new trait takes effect. No forced leader/policy toggle. New v4 games initialize it normally. Native upgrade tests remain outstanding. |
| General enemy demolition | **PARTIALLY SOLVED:** native-legal demolition preserved; own-founded/protected major settlements can be subjugated once without ownership/reward. Own-founded early CanRaze rejection still blocks complete destruction permission; general demolition remains engine blocked. Capitals/holy/city-state settlements are never illegally destroyed. |
| Full population-only remote workers | **ENGINE BLOCKED:** P80/M30/Q0 has 50 safe remotes; P150 has 120. No arbitrary forced-default reservation or functional automation-disable task is exposed. Slots/locks/specialists affect capacity. No fabricated population, negative automatons or unlimited buildings. |
| Citizen accounting and six yields | Protected real defaults fund every remote job. Local + remote + specialists + idle + genuinely unassigned = ordinary population; center free. Automatons separate, ambiguous credits suspended. Gross terrain and signed default compensation are journalled; modifiers once. |
| Native worked effects | **PARTIALLY SOLVED:** evaluated six yields, explicit native terrain-Culture Tourism refresh, and assigned-only native-rate improvement upgrade progress. Native worked counters/per-X/religious context, GP improvement bonuses, resource discovery, animations/replay and third-party worked queries remain missing. See [effect matrix](WorkedTileEffects.md). |
| Immediate one-city ownership | **PARTIALLY SOLVED:** founding/training/buyout/ordinary capture guarded, legal deferred recovery retained, extra-city native border-selection/new-route vetoes added. No universal pre-acquisition veto; arbitrary gifts/scripts can still produce transient ownership. |
| Quarantine economics | Queues/production/ordinary rates/purchases/associated remote plots guarded. Resources, Happiness, global building/wonder effects, existing routes, specialist GPP, total population/city counts/prerequisites, bombard/rebase/access/UI and pre-dispatch rewards are not comprehensively suppressed. Resistance is not an inert-city flag. |
| Boundless Domination | **UNVERIFIED:** native Game.SetWinner integration implemented after every ever-alive other-team rival original capital is legitimately subjugated. Eliminated rivals remain required; missing/replaced originals block. Own original/one-city/enabled-victory/no-prior-winner gates apply. Optional Config.SubjugationDomination can disable it. Foreign ordinary rules remain unchanged; live winner/UI/scenario testing required. |
| AI and scalability | Shared safe military validation and deferred adjacent/city-dirty checks; cached Surveyor planner and path budget retained. Native tactics, path completion, late-game FPS and save size untested. New development O(remote jobs), domination O(major slots), no regular new world scan/polling. |
| Saves and faults | Explicit known-version 1→2→3 Lua migration, native Player/Plot authority, optional mirror nonfatal, future/corrupt payloads preserved/disabled. Externally erased sources cannot safely be guessed away. Development saves turn before native mutations; interruption may skip remaining progress for one turn rather than duplicate it. No downgrading guarantee. |

The P40 fixture supports 30 remotes through verified local withdrawals; 10 is its unforced-surplus lower bound. Capacity examples use thirty owned native positions and no specialist slots; real games may differ. Every new mechanism needs native tests, especially older-save survival, original recapture, Tourism cache ordering, upgrade timing, quarantine GPP/infrastructure and victory completion.

No custom DLL is shipped. [OptionalDLLExtensions.md](OptionalDLLExtensions.md) proposes selective capture, independent demolition legality, authoritative reservations/native remote jobs and an atomic acquisition veto. The implementation preserves current safe boundaries while adding the feasible partial functionality.
