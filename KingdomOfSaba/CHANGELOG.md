# Kingdom of Saba changelog

## 1.0.0 implementation preview — 2026-10-23

- Implemented human-only Saba under Karib'il Watar with Ma'rib first, 23 regional ancient South Arabian city names, ten period-inspired spy names and complete English presentation.
- Added exact independent River/Desert city bonuses with zero/one native building counts, initial/load/founding/acquisition reconciliation and owner-turn repair. Destruction retains no stale city objects.
- Added full active Spearman/Water Mill inheritance, native defense-only Desert/+1 Sight promotion lost on upgrade and additive Cistern Food/Gold.
- Added original leader/loading art, collection-style symbols and map, 40 mipmapped DDS textures and reproduction sources. Reused native Spearman 3D art; no custom animated leader or unit model.
- Added real-schema preservation/inheritance checks, CP source contracts, three Lua 5.1 simulation suites and package checks. Actual command results and native cases are recorded in [Testing.md](docs/Testing.md). Native play, rendering and save acceptance are **NOT TESTED IN GAME**.
