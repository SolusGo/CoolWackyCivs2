# Trainer Red corrective audit — 2026-10-16

The corrective implementation and automated checks are complete. **Native Civ V gameplay, AI matches and native save round trips are NOT RUN.** This is source-backed validation plus simulation coverage, not a claim of full native certification. Further native testing is required using [Testing.md](Testing.md).

No intended numerical bonus, Training threshold/source, roster capacity, identity power, cooldown, project cost/scaling, eight-turn Standard absence or -10% Gold/Production modifier changed. Existing version-1 save ledgers gain optional fields; serials, claims and snapshots retain their authority. The collection UUID/version and other civilizations' gameplay are unchanged. The engine's one-project completion limit enforces the existing one-time design.

## Native source evidence

Reference: [official CP v151 commit 44c1e14ff75d80c1dba5c8a71e8289439a53aafb](https://github.com/LoneGazebo/Community-Patch-DLL/tree/44c1e14ff75d80c1dba5c8a71e8289439a53aafb/CvGameCoreDLL_Expansion2).

- `CvCity::canCreate` and `CvPlayer::canCreate` use TESTALL with `(owner,city,project)` and `(player,project)` respectively. `CustomMods.h` defines airlift `(player,unit,x,y)`, UnitPromoted `(player,unit,promotion)` and existing combat/lifecycle signatures.
- `CvLuaCity::lGetOrderFromQueue` returns five scalar values. `lPushOrder` reads pop/append with lua_toboolean; Lua numeric zero would be true, so code uses actual booleans.
- `getAirliftFromPlot` grants TESTANY permission before native domain/hasMoved restrictions. Lua reproduces those restrictions explicitly. `canAirliftAt` still checks MOVEFLAG_DESTINATION, water and adjacent enemies. `airlift` calls finishMoves before setXY; built-in missions do not provide a universal CustomMissionCompleted callback.
- `CvUnit::DoFallBack` has no Lua veto and places escorts after the main unit. Combat invokes it for heavy charge, morale and pre-resolution withdrawal. AI push/swap and unrelated scripted movement are separate paths. Deferred correction avoids mutating an in-progress native placement stack.
- `setMoves` clamps at zero; `IsPromotionValid` is a real native method; `InitUnit` calls SetXY before its final UnitCreated hook. Static registration checks cover 120 invoked native method names; the critical contracts above are checked against implementation bodies.

## Results and limits

Automated results are recorded in [Validation.json](Validation.json). Red's seven suites, actual-schema/standalone SQL, Lua 5.1, critical CP source contracts, existing civilization regressions, shared UI regressions, art/manifests/packages and existing synthetic benchmark are required for this change. Injected errors in test output are expected recovery stimuli.

CP v151 cannot provide absolute displacement immunity through these Lua hooks. A blocked anchor or an unobserved movement path is left alone. Static spawn filtering is conservative for arbitrary third-party terrain overrides. Unknown native unit-private fields, third-party Lua state, cargo relationships and mission queues cannot be generically restored. Airlift's bounded timeout favors releasing reservations and revoking custom permission over leaving a permanent grant; a native engine test must establish scheduling under animation/load. Existing Airports or other mods' independent grants remain native.

No permanent UI frame polling or gameplay mutation during rendering was added. Follow-ups exist only while an explicit mission is pending or one native-placement correction is queued. Multiplayer remains disabled and untested. **Native Civ V verification remains required before describing this preview as fully stable in live gameplay.**
