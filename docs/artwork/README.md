# Repository artwork

[Collection README](../../README.md) · [Civilization gallery](../Civilizations.md)

The cover was created for this repository using built-in ImageGen. Each JPEG in `leaders/` is a web preview of the matching civilization's diplomacy scene. The original texture is the `FallbackImage` named in that civilization's `Art/*LeaderScene.xml`.

## Cover prompt

```text
Use case: stylized-concept. Asset type: wide GitHub README cover illustration for the second Cool Wacky Civs mod pack. Paint one coherent panorama of a playful, densely built canal metropolis at blue hour inspired by the Boundless City, the pigeon couriers, the Lantern Fleet and the Wandering Circus: layers of bridges and sun-warmed masonry, a flight of messenger pigeons, lantern barges, and one small striped circus pavilion along the quay. Warm orange lanterns mingle with indigo and jade reflections. Richly rendered painterly strategy-game concept art, inviting and bustling, strong hierarchy and a single perspective, artfully grounded and legible as a small thumbnail. Compose as an ultra-wide landscape banner (ideally 3:1) with all the important scenery in the central horizontal third so it can be cropped wide. No title, typography, lettering, interface, frame, logos, or watermark.
```
