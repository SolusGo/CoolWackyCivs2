# Covenant graphics revision — 2026-11-06

The Covenant now has original 2D artwork instead of stock Egypt/Ramesses/Shrine/Temple portraits. The implementation follows the most recent civilizations' format: nine atlas sizes, 90% gold-framed colour cells, 75% padded leader cells, a tintable white alpha/flag, static leader fallback XML, full-mip legacy DDS, separate Dawn image and a fictional map.

The set comprises 43 DDS textures, one leader-scene XML and `03_COVENANT_Art.sql`. Five raw built-in imagegen paintings, the exact prompt set, deterministic emblem/UI generation and retained atlas masters are in `art-source/TheCovenant` and `art-source/IconAtlasMasters`. Compile with `tools/prepare_covenant_art.py`; preview with `tools/preview_covenant.py`. The normal builder discovers and registers the new files in the ModBuddy project and manifest.

The recall interface gains a bespoke navy-and-gold background, emblem, divider and four-state native button sheet. Its EditBox, callbacks, section text, mandatory queue lifecycle and study/reward rules remain unchanged. All decorative Images use `ConsumeMouse=0`; the existing outer modal backdrop still consumes outside clicks. The unavailable 28px font name is replaced with installed `TwCenMT24`. The leader scene is a static original painting, matching other fictional leaders in the collection; there is no new animated 3D leader model. Existing native unit/building models are retained, and Egypt's loading narration is silenced.

The focused validator checks all mip chains, atlas slots, native image dimensions, source-to-compiled framing, custom scene/loading/map references, complete manifest imports, and gameplay-table equality across the art overlay. Shared validation checks the new families alongside the whole collection. Native rendering was not performed; previews explicitly use modeled layout/font metrics. Existing save keys, curriculum identity, civilization identifiers, UUID and numerical balance are preserved.

The [AuditReport.md](AuditReport.md) covers the current implementation, including the subsequent action-recovery correction. [GraphicsValidation.json](GraphicsValidation.json) retains the evidence captured at the graphics-only revision; its Lua equality and 18-group statements describe that earlier stage. The current suite includes 22 additional UI/persistence groups. A current release receipt is supplied with the rebuilt distribution.
