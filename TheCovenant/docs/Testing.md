# Covenant validation and native acceptance

Run `python tools/validate_covenant.py` with the repository's development dependencies. Database checks use the existing read-only BNW/CP database adapter and explicit prerequisites.

Offline checks execute the shipped Lua 5.1 engine and mock UI. They cover all supplied wording, corrected John 14:29, missing/extra/reordered words, separate reference components/ranges, Unicode punctuation/spaces/edits, five introductions, same-turn anti-farming, clean streaks, bounded review intervals, rotating and overdue examinations, carried sessions, numbered-section/exam restoration, original v24 migration, invalid payloads, bulk-edit rejection, study timers, unhandled-input capture, repeated callbacks, era-scaled rewards and balanced timer semaphores. The queue fixture models waiting/preemption and asserts one entry, unchanged eUtmost priority, preserved draft/focus and no periodic churn. It cannot establish actual native dispatch order or native queue semantics.

Fault-injection scenarios reproduce and prevent a permanently latched Submit guard after a render exception. They exercise both Submit and Study, retry a failed progression save without replaying its answer, and fail immediately after Faith is changed to verify that recovery never repeats the journalled reward. A recovered final introduction must display a newly due exam's actual reference prompt without releasing the gate or duplicating its queue entry. The focused suite now contains 18 engine groups and 25 additional UI/persistence groups. These are Lua/mock results, not native engine fault tests.

The feedback revision retains exact 9.75/10-second boundary checks for all five introductions and restudies. Masking checks cover full-section context, spelling mistakes, missing/extra words, adjacent swaps, multiple errors, repeated words, punctuation/case/apostrophes, long input and UI-markup isolation. UI checks verify the exact masked section and assisted restart without rewards. The old `FirstDifference` numeric result and serialized save format remain compatible.

Installed Firaxis scripts/XML are inspected read-only for the modal/EditBox and SaveData call contracts; their hashes are recorded in [SourceAudit.json](SourceAudit.json). The package check verifies hashes, VFS flags, control IDs and XML. SQL checks validate human-only selection, trait/leader links, starts, exact yields, cost/technology/maintenance/prerequisite inheritance, native models and localization while preserving existing rows in an in-memory BNW/CP v151 clone. [AuditReport.md](AuditReport.md) records the current reliability audit.

Graphics validation decodes all 43 original DDS textures, checks complete legacy mip chains including 45px cells, verifies the 37 atlas declarations and every portrait slot, and checks exact UI texture dimensions/native button-state geometry. It compares compiled colour cells against the shared gold-frame compiler and snapshots every gameplay table around the art SQL overlay to prove that only presentation changes. The collection icon validator additionally checks all families' gold rims and 90%/75% framing. `python tools/preview_covenant.py` renders the current shipped Lua/XML/DDS using modeled font metrics; those PNGs are not native screenshots. [Graphics.md](Graphics.md) documents the art revision.

On 2026-11-06, the existing turn-10 Covenant autosave was loaded in native DX11. The first Revelation study screen and its live countdown were observed on screen. Reloading made the previously pending screen visible; the cause of its earlier invisibility remains unconfirmed. This observation preceded the 10-second/detailed-feedback revision. Native typing, error-feedback layout, popup preemption and full save/reward round trips remain acceptance checks; the broader native suite has **not** been passed.

## Native checklist

1. Enable BNW, Community Patch v151 and Cool Wacky Civs 2 v24. Start a new single-player Covenant game.
2. Confirm the opening study gate precedes unit actions and all numbered Revelation sections fit. Confirm every study/restudy unlocks after 10 visible seconds, with hidden time paused.
3. Confirm ordinary letters, numbers, punctuation, spaces and Unicode quotes type correctly. Check Backspace/Delete, Home/End, cursor arrows, selection replacement, Enter/Return, Escape, F-keys/game shortcuts, Ctrl+V, Shift+Insert, outside clicks and focus changes. Enter must not submit; outside clicks and Escape must not dismiss. Verify bulk paste rejection without rejecting single-character edits. One-character/shared-text paste is an acknowledged limitation.
4. Type a wrong word and confirm feedback shows the whole section with that word replaced by `____`. Test a missing word, extra word and swapped pair; correct later words must remain visible. Verify long masked feedback fits above the buttons. Confirm the passage restarts at its reference, then complete every section. Confirm play resumes and no learning-attempt reward appears.
5. Confirm the first five turns introduce the five passages. Confirm subsequent reviews and the campaign-turn-10 five-passage exam.
6. Save mid-section and during an exam, quit and reload from the modded load screen. Confirm remaining checks, assistance and reward limits persist.
7. Test at 1024×768 and a larger resolution, alongside the pack's other panels and native popups. Test a new game as another pack civilization and confirm no Covenant gate.
8. Queue native popups before the Covenant gate and preempt a visible recall. Verify it waits/resumes with one queue entry, eUtmost priority and no flicker. Repeated show/hide/turn/load callbacks must neither leak nor double-release the semaphore. Reopening must retain the draft. Test a forced foreign dequeue separately: unsupported external queue mutation is not guaranteed recoverable.
9. Carry a review/exam over a turn change, and skip across a tenth-turn boundary in a controlled test. Finish the prior queue and verify the newly due exam stays mandatory without an unlocked interval. Verify one ordinary review and one reward maximum per actual turn.
10. Load an original v24 save mid-section and mid-exam; retain progress, failures, assisted status, mastery and the reward cap. Save the upgraded state and reload it. Start a separate campaign with the same player slot and verify fresh progress. Repeat with an advanced-era start.
11. Check the new emblem and padded Scribe portrait in setup/Civilopedia, both building portraits, the silent Dawn image, fictional map, static leader fallback scene and all button states. Confirm the white alpha emblem tints navy/gold correctly, texture edges are clean, and the recall text remains readable at 1024x768 and 1920x1080.

Do not report these native checks as passed until they have been played.
