# Covenant implementation

`CovenantGate.xml` is the sole simulation-owning InGameUIAddin. It includes the namespaced verse data and pure Lua 5.1 memory engine. The engine has no Civ API calls, so its exact matching, progression and numeric serialization are exercised directly by tests.

The gate checks for the living active human Covenant player and excludes network games and hotseat. It queues at `PopupPriority.eUtmost`, consumes unhandled input, covers the game surface and owns one turn-timer semaphore while shown. A quarter-second check repairs missed load/turn notifications or a gate that this module closed when the player became ineligible. A hidden context retains its local queue ownership: another popup may legitimately be active. It is never dequeued/requeued just because it is hidden. Show/hide ownership is idempotent; close releases any remaining owned semaphore even if no hide callback arrives. Study countdowns advance only while visible. Completion checks for a newly due examination before releasing the gate.

Submit and Study share an exception-safe action guard. If an action fails after changing progression, further actions wait while the existing periodic check retries the save and refreshes the current prompt. Recovery clears stale answer text and preserves queue/timer ownership; it never executes the answer or yield grant again. A permanent storage/control failure still requires fixing that underlying failure. A reward call that fails after a native mutation can leave a partial or forfeited reward; the journal prevents retrying and duplicating that mutation.

The word matcher lowercases text, standardises quotes, ignores punctuation and normalises whitespace, including common Unicode spaces. It retains word order and spelling. Reference matching parses the book, chapter, first verse and optional last verse independently. A colon is required; spaces and hyphen/en/em-dash variants are accepted. Wrong or missing ranges, extra tokens, split digits and zero/leading-zero numbers fail. All five supplied passages remain unchanged.

The input handler and XML retain the installed Firaxis SetCityName/SetUnitName pattern: `CallOnChar=1`, `EditMode=1`, an EditBox change callback, and a context handler returning true for unhandled input. Ordinary keys never reset text or force focus. Reopening restores focus without deleting the draft. Only clicking Submit processes an answer; Enter/lost-focus callbacks do not submit. A new edit is required between submissions, including a deletion to empty text (which fails recall). Single UTF-8 character edits are accepted; multi-character insertion changes, including ordinary replacement pastes, are rejected. This cannot identify clipboard origin, one-character paste, every selection replacement with shared text, or distinguish batched native edits/IME from paste. Native dispatch remains an acceptance requirement, not a proven anti-cheat property.

`Modding.OpenSaveData()` is the per-save game database, distinct from `OpenUserData`; campaigns have separate stores. The existing `CovenantMemory_v1_<curriculum>_P<player>` keys already distinguish the module, curriculum and player within a save and remain unchanged. Calls now follow shipped dot notation. Numeric-only schema 2 records the reward turn with completion/progression in one payload. Schema 1 is accepted and migrated in place, merging its separate `_RewardTurn` marker. Existing start-turn anchors, lessons, assistance, failures, queues, sections and streaks are retained. Schema 2 is an upgrade; the original schema-1-only UI cannot read upgraded payloads. Keep a backup if downgrading the mod.

Payload size, numbers, flags, phases, queues and internal invariants are checked without executing saved text. Corrupt/unknown/future-dated payloads restart with mandatory assisted study. Valid original v24 progress is preserved. Reward entitlement is journalled before applying the unchanged Faith/Culture values; the legacy marker is also maintained. A script failure after journalling may forfeit a reward rather than duplicate it. Native game-save/resource atomicity is not proven by offline tests.

New campaigns use `Game.GetStartTurn()` for cadence, including advanced-era starts and delayed UI initialization. Completing a carried session schedules the next review from the current turn and clears that turn, preventing a second ordinary review. Examination queues survive interruptions. The latest overdue tenth-turn examination is caught up after introductions or an older pending queue; order rotates by campaign examination number. Existing saves retain their original start-turn anchor.

No verified per-context popup queue membership query was found in the shipped scripts. Local ownership repairs known transitions without inventing an API. Initial rendering must succeed before ownership is recorded; failed queue calls roll back their own request and retry. The check guard clears after an exception, and stale show notifications with no eligible pending session cannot acquire a semaphore. An unrelated mod forcibly dequeuing/hiding this context without notifying its owner cannot be reliably distinguished from legitimate queue suspension. Recovery from arbitrary foreign queue mutation is therefore not guaranteed. Ordinary queue suspension is modeled; real popup arbitration and turn blocking require native acceptance.

Core SQL adds new rows only. Replacement buildings copy selected native cost/technology/maintenance/model fields and Temple prerequisite classes, then apply fixed custom yields. This is not a complete clone of every possible companion-table effect supplied by unrelated building overhaul mods. `03_COVENANT_Art.sql` registers 37 custom atlas/size rows and updates only the Covenant's 2D presentation: civilization/leader/building portraits, tintable emblem, static leader scene, Dawn image and fictional map. Native civilization/building/unit 3D models remain inherited. The original Egypt narration is silenced, matching the pack's fictional leaders.

`prepare_covenant_art.py` compiles the five retained original paintings, code-native Scripture/quill heraldry and UI materials into 43 complete-mip legacy RGBA DDS textures. Colour medallions use the shared 90% diameter; leader portraits use 75% padding. The nine sizes, two-cell building atlas, monochrome alpha/flag and scene sizes match the latest other civilizations. The mandatory UI keeps its own queue/input lifecycle and gains a full-size 920x640 theme background, native 44x180 four-state button sheet and correctly sized divider. No Shared UI auto-close helper is introduced into the mandatory gate. The title uses the installed `TwCenMT24` font.

The collection retains its UUID, minimum compatible save version and all prior civilization identities. The new module is appended after the released SQL inventory. No existing civilization gameplay or art source is changed.
